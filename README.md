## 复现步骤（约 15 分钟）

**第 1 步 · 开通百炼**：登录 [阿里云百炼](https://bailian.console.aliyun.com)，新用户有免费额度，按引导开通。

**第 2 步 · 建知识库**：控制台 → 知识库 → 新建 → 上传本仓库 `knowledge/` 目录下 4 个文档 **+ `template/output-template.md`**（共 5 个，一个都不能少：三剧知识库供检索，输出模板供渲染，机位图库供配图）。

**第 3 步 · 建智能体**：控制台 → Managed Agents → 创建智能体：
- 模型：GLM-5.1（或其他百炼托管模型）
- 系统提示词：粘贴 `prompt/system-prompt.md` 全文（从「你是入戏」开始，到文末）
- 知识库：关联第 2 步的知识库
- 工具：接入 **flyai skill**（飞猪官方 skill，实时商品库；免费试用无需 API key，配置 key 可解锁完整价格）

**第 4 步 · 对话验证**，依次输入：

```
我想跟着《去有风的地方》去大理，成都出发 3 天慢节奏，我自己一个人
```

智能体将：检索剧知识库 → flyai 实查机票/民宿/门票 → 编排逐日动线 → 输出打卡手帐（含高德导航链接 + 台词机位四件套 + 飞猪预订链接）。

再试边界测试（验证不编造）：

```
有没有《狂飙》的取景地？
```

预期回答：如实告知知识库未收录（目前收录三部剧），不现场编造。

## 架构说明

- **内容层**（百炼 Managed Agent · GLM-5.1）：剧知识库检索 + flyai 实时库存查询 + 逐日动线编排 + 手帐内容生成
- **渲染层**（输出模板 + 渲染 skill）：手帐视觉、坐标→高德导航链接（`uri.amap.com/marker`，规则固化在模板）、飞猪预订票根——保证每次输出一致可用
- 裸 agent 未挂输出模板时会输出朴素 HTML 且默认给 Google Maps 链接（大陆不可达）——这正是模板层存在的意义

## 数据与信源说明

- 机票/酒店/门票价格与预订链接：飞猪实时查询（demo 页价格为生成日实价，以预订时为准）
- 剧知识库信源：大理文旅官网、新华网、央广网、人民网等官方与权威媒体，逐条交叉核验；单源存疑信息保留「待核验」标注，台词逐字引用并标注出处状态
